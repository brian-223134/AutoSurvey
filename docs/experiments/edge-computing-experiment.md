- **단어 수 기준 주의**: 이 표는 run.json 의 tex 본문 단어 수다.
  `commoncorpus-setup.md` §6~7 의 표는 `.md` 원문 기준이라 더 크다
  (판 A: .md 18,264 / 중복 헤딩 제거 15,794 / tex 본문 15,206).
  발표에서 한 기준만 쓴다면 **tex 본문(= PDF 에 실제 실린 텍스트)** 을 권장.
- **판 B 는 실패가 아니라 드리프트 사례**: `--section_num` 이 soft 라 5 지시 → 8이
  나온 판. 이 관측이 `--enforce_section_num`(커밋 `64be6f3`) 도입의 근거고,
  판 D 가 그 검증 실행(섹션 5 고정 성공)이다.
- **디렉터리명 함정**: `-8k` 디렉터리가 32쪽짜리 판 B 고, 실제 8k 토큰 달성판은
  `-20p`(판 C)다. 실행 당시 saving_path 를 보존해서 이름과 결과가 어긋났다.

## 2. 비용 상세 — 단계별 토큰과 청구

AutoSurvey 의 비용은 outline(러프 아웃라인 N회 + merge)과 writer(서브섹션 초안
+ refine)에서 나온다. 재시도는 전부 429(스로틀)였고 최종 실패는 없다.

| 판 | outline in/out 토큰 | outline 비용 | writer in/out 토큰 | writer 비용 | 재시도 | 합계 |
|---|---|---|---|---|---|---|
| A | 422,133 / 8,820 | $0.0885 | 875,598 / 70,229 | $0.2073 | 3 | **$0.2958** |
| B | 419,867 / 7,044 | $0.0872 | 747,234 / 46,986 | $0.1705 | 2 | **$0.2577** |
| C | 378,869 / 5,068 | $0.0782 | 328,222 / 21,794 | $0.0762 | 0 | **$0.1544** |
| D | 377,730 / 4,700 | $0.0778 | 327,040 / 19,815 | $0.0750 | 0 | **$0.1528** |

- 4판 합계 **$0.86** (+ 판 A 1차 시도가 세션 종료에 휘말려 매몰된 ~$0.22 별도,
  `commoncorpus-setup.md` §6 사건 기록).
- outline 비용은 4판이 $0.078~0.089 로 거의 상수 — `outline_reference_num 1200` 이
  지배해서 분량 설정과 무관. **분량을 줄이면 writer 비용만 비례해서 준다.**
- 추정치와 실제 청구치 오차 전부 1% 미만 (provider 핀 + reasoning 토큰 0 이라
  단가표 그대로 맞음).
